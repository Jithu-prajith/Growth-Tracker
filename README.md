## 🌟 Key Features

### 1. Daily Schedule (Spine of the App)
- **Hostel Calibrated Timetable**:
  - `5:30 AM` — Gym (MUST)
  - `6:30 AM` — Harry Potter + Filter Coffee (MUST)
  - `7:15 AM` — 1 LeetCode Problem (DSA in Python)
    - **Side-by-side buttons**: "Open Striver's" (takeuforward.org) & "Open LeetCode" (leetcode.com).
    - **Auto-topic injection**: Shows *"Today's topic: [next pending/in-progress DSA topic]"*.
  - `7:40 AM – 8:30 AM` — Breakfast
  - `9:15 AM – 4:40 PM` — College (Lunch at 12:30 PM)
  - `4:40 PM` — ServiceNow / Roadmap Study (30 min)
    - **Auto-topic injection**: Shows *"Today's topic: [next pending/in-progress ServiceNow topic]"*.
  - `5:30 PM` — **WhatsApp 10-min countdown timer widget** (college notices only)
  - `5:45 PM` — **Bath + freshen up**
  - `6:00 PM – 6:45 PM` — **Data Science study block** (Tag: Teal)
    - **Auto-topic injection**: Shows *"Today's topic: [next pending/in-progress DS topic]"*.
  - `6:45 PM – 7:20 PM` — **Light walk / active rest (No phone)** (Tag: Amber)
    - **3-day skip nudge**: *"Rest is not laziness. Hrithik rests too."*
  - `7:20 PM – 7:40 PM` — **Head to dinner early** (Tag: Amber)
    - Small reminder: *"Go now — food runs out fast."*
  - `7:40 PM` — Dinner (Dynamic, mark when done)
  - `9:20 PM` — Parents Call (MUST, 10 min)
  - `9:30 PM – 11:00 PM` — **Phone Submitted: Zero-Distraction Deep Work** (ServiceNow PDI / Projects)
  - `11:00 PM` — Sleep
- **Day-Aware Variants**:
  - **Friday**: BGMI gaming session allowed after parents call (1 hr reward).
  - **Saturday**: 2-hour ServiceNow deep session + 1.5-hour portfolio project + BGMI.
  - **Sunday**: Light gym & stretch, 1-hour Harry Potter, weekly review & roadmap planning, BGMI, light ServiceNow revision.
- **Celebration Trigger**: When all `MUST` items are completed, launches confetti and displays: *"All MUSTs done. Shri Prajith, you're building the life you dreamed of."*

### 4. Data Science & Machine Learning Roadmap (Striver-Style)
- **7 Progressive Phases (70% Phase Lock progression)**:
  1. **Phase 1 — Python for Data Science**: Variables, loops, functions, lists/dicts/sets, file handling, NumPy arrays/vectorization, pandas DataFrames/read_csv/groupby, Matplotlib & Seaborn charts. (Resource: CS50P + Kaggle).
  2. **Phase 2 — Statistics & Math for ML**: Descriptive stats, probability basics, normal distribution/CLT, hypothesis testing/p-value, correlation/covariance, linear algebra vectors/matrices. (Resource: 3Blue1Brown).
  3. **Phase 3 — Data Cleaning & EDA**: Missing values, outlier detection, feature engineering basics, real datasets EDA, visual storytelling. (Resource: Kaggle datasets).
  4. **Phase 4 — Machine Learning Core**: What is ML, Linear Regression, Logistic Regression, Decision Trees, Random Forest, SVM, KNN, K-Means Clustering, evaluation metrics (ROC-AUC/F1), cross-validation & scikit-learn workflow. (Resource: Krish Naik + scikit-learn docs).
  5. **Phase 5 — Advanced Machine Learning**: XGBoost, LightGBM, PCA dimensionality reduction, scikit-learn Pipelines, feature selection, SMOTE imbalanced data. (Resource: CampusX).
  6. **Phase 6 — Deep Learning Basics**: Neural networks, perceptron, activation functions, backpropagation, TensorFlow/Keras, CNNs, NLP tokenization/word embeddings. (Resource: Andrew Ng Deep Learning Coursera).
  7. **Phase 7 — Projects & Production Deployment**: End-to-end ML project on Kaggle, Streamlit deployment, Hugging Face Spaces, GitHub portfolio, Kaggle competitions. (Resource: Kaggle + GitHub).
- Checkboxes, estimated time, actual logged hours, notes, and resource links.

### 5. Physical Foundation & Nutrition Engine
- **Hardcoded 6-Day Push/Pull/Legs Split**:
  - Day 1: Push (Barbell press, DB shoulder press 6kg, Dips, Lateral raise 6kg, Close-grip push-ups)
  - Day 2: Pull (Pull-ups, DB row 6kg, DB curl 6kg, Dips triceps, Hammer curl 6kg)
  - Day 3: Legs+Core (Bodyweight squats, Bulgarian split squat, Goblet squat 6kg, Glute bridge, Plank)
  - Day 4: Push Progressive (Barbell press progressive, Wide push-ups, Front raise, Weighted dips, Tricep extension 6kg)
  - Day 5: Pull Progressive (Pull-ups max+1, Single-arm row, Chin-ups, Concentration curl, Face pulls)
  - Day 6: Legs+Core Harder (Jump squats, Walking lunges, Single-leg calf raises, Hanging knee raises, Ab crunch+leg raise)
  - Day 7: Active Recovery & Mobility
- **Hostel Room / Resistance Band Backup Mode**: Instant toggle for days when the gym is crowded or inaccessible.
- **Skip Nudge**: *"You skipped gym today. Your hill farm and tribal school need a healthy you."*
- **Vegetarian Diet Tracker**:
  - 5 planned meals (Oats/groundnuts, peanut butter toast, soya chunks curry, roasted chana, rajma/chole).
  - Target: **95g Protein**, 2300 kcal, and **8 glasses of water (3 Litres)** with progress bars.

### 6. Daily Reflection Journal
- Embedded at the bottom of the daily schedule.
- Auto-saves continuously to disk and cloud.
- Live word counter.
- Rotates across **30 curated prompts** (e.g. hill farm reflections, technical breakthroughs, parents' sacrifices).
- Past entries date browser.

### 7. Hybrid Persistence & Cloud Sync
- Works offline out of the box with zero setup via reactive `localStorage`.
- Connects to Google Sign-In and Firebase Cloud Firestore when API keys are added.
- One-click JSON backup export & restore.
